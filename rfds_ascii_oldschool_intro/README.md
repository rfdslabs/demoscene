# rfds_ascii_oldschool_intro

Old school ASCII-art RFDS demo:

- colorful animated `RFDS` ASCII logo
- wobble/float movement and glow ghosting
- starfield background with retro vibe
- bottom sine scroller text
- procedural chiptune-style background audio

## Build

```bash
cd rfds_ascii_oldschool_intro
cmake -S . -B build
cmake --build build -j
```

## Run

```bash
./build/rfds_ascii_oldschool_intro
```

## Controls

- `Esc`: quit
- `F`: fullscreen
