# rfds_amber_crt_intro

Alternative RFDS demo style:

- amber CRT color palette
- sine scroller (`RFDS WAS HERE`)
- `R/F/D/S` beat-synced active letter pulse
- generated 125 BPM funk-style groove

## Build

```bash
cd rfds_amber_crt_intro
cmake -S . -B build
cmake --build build -j
```

## Run

```bash
./build/rfds_amber_crt_intro
```

## Controls

- `Esc`: quit
- `F`: fullscreen
