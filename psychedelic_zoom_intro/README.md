# psychedelic_zoom_intro

Psychedelic visual demo:

- very colorful palette animation
- infinite zoom cycles
- kaleidoscope folding + fractal warp
- strobe flashes and moving color bands

## Build

```bash
cd psychedelic_zoom_intro
cmake -S . -B build
cmake --build build -j
```

## Run

```bash
./build/psychedelic_zoom_intro
```

## Controls

- `Esc`: quit
- `F`: fullscreen
